# 데이터 출처·라벨·권리

이 저장소에는 데이터나 가중치가 없습니다. 아래 출처에서 이용 자격과 조건을 확인하고 직접 취득해야 합니다. 데이터 다운로드 도구는 접근 권한이나 재배포 허가를 대신하지 않습니다. 데이터·파생 마스크·raw manifest는 로컬 `data/`, `datasets/`, `configs/local/`에 보관하고 Git에 추가하지 않습니다.

AI Hub FAQ는 원천 자료와 그 단순 편집·가공본의 재배포를 제한하고 학습으로 생성한 AI 산출물과 구분합니다. 이 배포는 보수적으로 이미지·annotation·mask와 모든 가중치를 제외합니다. AI Hub 모델 일반의 배포가 항상 금지된다는 뜻은 아니며, 혼합 자료로 학습한 모델의 제공 여부는 각 원천 조건과 모델 라이선스를 함께 검토해야 합니다.

AI Hub 원 출처 명칭은 **상용 자율주행차 주간 도심도로 데이터**, **상용 자율주행차 주간 자동차 전용도로 데이터**, **상용 자율주행차 야간 자동차 전용도로 데이터**입니다. 13/14/15는 이 실험의 로컬 별칭이며 AI Hub의 공식 dataset ID가 아닙니다. [주간 도심도로 원본 데이터 상세](https://www.aihub.or.kr/aihubdata/data/view.do?currMenu=115&dataSetSn=71563&topMenu=100)는 2022년 구축 polygon/3D 자료와 주관기관 ㈜미디어그룹사람과숲을 설명합니다. 같은 이름의 업사이클링 QA 자료가 별도로 있으므로 취득 시 실제 버전·파일 목록·라벨 형식을 확인해야 합니다. 이 실험은 관측한 polygon 라벨만 분할 감독으로 사용하며 자연어 QA를 분할/제어 정답으로 대체하지 않습니다.

## 선택된 스냅샷

현재 실험은 사용자가 선택한 **44개 ZIP**을 기준으로 합니다. 모든 AI Hub 다운로드가 완료되었다는 뜻이 아닙니다. ZIP의 전체 CRC와 SHA256을 확인하고 선택 증거를 보존한 뒤 새 폴더에 해제했습니다. 새 파일을 나중에 같은 고정집합에 자동 추가하지 않습니다.

AI Hub 13–15번의 polygon JSON 21,571프레임 중 잘못된 다각형이 있는 272프레임(학습 245, 검증 27)을 원본 annotation 해시를 포함한 격리 기록으로 제외했습니다. 남은 학습 18,932 / 검증 2,367에 전체 이미지 해독·클립 분리·바이트/RGB 중복 검사를 적용했습니다. 12번 자료는 선·사각형·관계/자연어 QA 형태이므로 이 이진 polygon 학습에 섞지 않았습니다. 자연어 답변을 실제 조향·제동 정답으로 쓰지 않습니다.

## 라벨 공간

| 값 | 의미 | 처리 |
|---|---|---|
| `0` | road | 각 출처가 정의한 도로 표면/주행 영역을 명시적으로 매핑 |
| `1` | nonroad | 명시적으로 주석된 비도로 클래스 |
| `255` | ignore | 미주석·모호한 의미·매핑되지 않은 영역; 학습 손실과 평가 분모에서 제외 |

기존 AI Hub 매핑에서 `trafficDrum`, `warningTriangle`이 ignore였음을 원본 annotation과 학습 표본으로 확인했습니다. 보정 버전에서는 이 두 클래스가 덮는 **기존 255 픽셀만 1로** 변경했습니다. `freespace` 또는 기존 road 픽셀을 지우지 않으며 unknown/background를 임의 nonroad로 채우지 않습니다. warningTriangle 이름 아래 독립 경고판도 관측되었으므로 이 수정은 이진 nonroad만 뒷받침하고 세부 객체 분류 정답을 재정의하지 않습니다.

## 완료한 CPU 전처리 버전

`aihub_training_preprocessed_v1`은 학습 풀 37,864장만 대상으로 새 manifest와 필요한 수정 마스크를 만듭니다. 84프레임을 재처리했고, 그중 **83프레임·137,436픽셀**이 실제 변경되었습니다. 나머지 1프레임은 대상 다각형이 기존 nonroad와 겹쳐 실제 변경이 없습니다. 대상 다각형은 343개(trafficDrum 339, warningTriangle 4)입니다. `report.json`의 `changed_frames=84`는 재처리 프레임 수이며 실제 픽셀 차이가 있는 프레임 수와 구분합니다.

| 출처 | 원래 학습 풀 | 새 train | 새 dev |
|---|---:|---:|---:|
| AI Hub 13 | 6,278 | 5,551 | 727 |
| AI Hub 14 | 6,351 | 5,736 | 615 |
| AI Hub 15 | 6,303 | 5,669 | 634 |
| BDD100K | 10,000 | 9,000 | 1,000 |
| Virtual KITTI 2 | 8,932 | 7,272 | 1,660 |
| 합계 | **37,864** | **33,228** | **4,636** |

개발 분할 목표는 10%, seed 42였지만 그룹을 통째로 보존해 실제 12.2438%가 되었습니다. BDD는 clip, VKITTI는 원본 scene의 카메라/환경 변형 전체, AI Hub는 장치/날짜 대리 그룹을 유지합니다. 바이트/RGB/원본 그룹이 연결된 표본은 같은 분할에 둡니다. 전체 풀은 정확히 한 번 train 또는 dev에 들어갑니다.

개발셋은 부모 모델이 이미 학습한 풀에서 나뉘었으므로 독립 시험셋이 아닙니다. 이후 후보의 선택용으로만 쓰고 공식 계약·public 40장은 보고용으로 유지합니다. 이 전처리 결과에 대한 새 후보의 성능은 [RESULTS](RESULTS.md)의 별도 상태를 확인합니다.

공식 검증 mask나 manifest를 수정하지 않았습니다. 독립 검증은 완료 표시·입출력 해시·정확한 분할·중복·고정 계약·변경 mask 배열을 확인합니다. 공식/public 현재 이미지의 새 재해독 검사가 아니라 고정 계약 기록 기준 비교라는 한계가 있습니다.

## 지원하지만 현재 결과와 구분하는 자료

[ACDC](https://acdc.vision.ee.ethz.ch/), [A2D2](https://www.a2d2.audi/), nuScenes 및 RC 자체 수집용 어댑터/형식도 연구 코드에 있습니다. 지원 코드, 다운로드, 전처리, 학습, 검증, 공개 권리 확인은 각각 다른 상태입니다. ACDC 추가 취득·준비는 별도 버전에서 진행하며 위 완료 성능표나 기존 고정집합에 자동 포함하지 않습니다. 새 결과가 없으면 개선 근거로 사용하지 않습니다.

데이터를 추가할 때는 데이터 버전, 취득일, 공식 약관/페이지, 원본과 annotation 해시, label map, 클립/그룹 정의, 분할 규칙, 중복 검사, 격리 사유, 무시 비율과 클래스/조건별 빈도를 함께 기록하십시오. 자료의 권리가 불명확하면 공개 배포에서 제외하고 다운로드 어댑터와 aggregate 통계만 제공합니다.

### ACDC 학습 GT 감사: 이미지 학습 결과와 구분

별도 준비 단계에서 학습 GT 1,600장을 CPU로 감사했습니다. 야간 학습 GT 400장의 ignore 픽셀 비율은 10.3108%였습니다. person/rider/motorcycle/bicycle/car/truck/bus/train이 주석된 프레임은 각각 **190/121/90/96/382/11/46/85장**입니다. 이는 원본 크기에서 라벨 픽셀 존재를 센 프레임 수이며 객체 instance 수가 아닙니다. 야간 장애물 감독이 더 있는 자료를 검토할 근거입니다. GT 검사만으로 RGB 다운로드·페어링·누수 검사·학습 완료를 선언하지 않으며, 기존 성능표에는 포함하지 않았습니다.
