# 데이터와 모델 개선의 판단 근거

2026-10-23 기준의 오프라인 연구 검토입니다. 아래 대안 중 구현하거나 측정하지 않은 방법의 효과를 이 프로젝트의 성능으로 제시하지 않습니다. 실제 완료 수치는 [RESULTS](RESULTS.md)를 참조합니다.

## 무엇이 문제였는가

기존 YOLO v2와 AI Hub 추가 학습 모델을 같은 384×640 입력, 도로 확률 임계값 0.65로 비교하면 전체 도로 IoU는 83.2851%에서 83.8095%로 올랐습니다. 그러나 기존 네 출처만의 IoU는 85.0139%에서 82.6446%로 낮아졌고, 전체 비도로→도로 픽셀 오인율은 1.6372%에서 2.8198%로 올랐습니다. 따라서 평균 IoU만으로 모델을 채택할 근거가 부족합니다.

확인된 데이터 문제는 다음과 같습니다.

- AI Hub의 trafficDrum과 warningTriangle이 기존 매핑에서 ignore였습니다. 원본 사람이 주석한 다각형만 사용해 비도로 감독 신호를 보강했습니다. 84프레임을 다시 처리했고, 실제 변경은 83프레임의 137,436픽셀입니다. 기존 도로 픽셀과 주석 없는 영역은 유지했습니다.
- AI Hub 야간 검증에는 보행자·자전거·오토바이·라이더·콘 주석이 없습니다. 이 조건에서의 장애물 성능은 현재 도로 IoU로 추정할 수 없습니다.
- 원래 라벨의 의미와 주석 범위가 다릅니다. BDD drivable area, Virtual KITTI road surface, AI Hub freespace를 이진화해도 같은 운용 정답이 되지는 않습니다. 부분 주석에서 비도로 감독 신호가 부족한 문제와 기존 출처를 잊는 문제가 동시에 있을 수 있습니다.

앞의 두 항목은 실제 자료에서 확인했습니다. 출처 변화와 망각이 회귀를 얼마나 설명하는지는 **원인 가설**이며, 이 비교만으로 인과관계를 확정하지 않습니다. 83프레임의 수정이 전체 회귀를 해결할 것이라고 가정하지도 않습니다.

격리가 야간 라벨 부족을 만들었는지도 추가 확인했습니다. 제외한 학습 JSON 245개의 SHA와 geometry 오류를 재검증했으며, 그중 야간 66프레임에는 위 희소 장애물 클래스 주석이 없었습니다. 따라서 해당 클래스의 야간 학습 프레임 수는 격리 전후 동일하며, 희소 주석 문제는 이 스냅샷의 격리 이전부터 존재했습니다. 영상 자체를 다시 읽은 검사가 아니므로 실제 객체 부재와 주석 누락을 구별하지는 못합니다.

주간 도심에서는 정상 geometry의 희소 클래스 주석을 포함한 50프레임이 다른 다각형 오류와 함께 격리되어 감독 신호를 일부 잃었습니다. 전체 격리 학습 중 141프레임은 오류가 ignore/background 클래스에만 있었지만, 잘못된 polygon을 단순 삭제하면 겹친 road 픽셀이 새로 감독될 수 있습니다. 이번 고정 실험에서는 복구하지 않았으며, 별도 사람 검토·보수적인 ignore 처리·분할 검증을 거치는 후속 전처리 대상으로 남깁니다. [격리의 학습 라벨 영향 집계](../reports/quarantine_training_coverage.json)

## 실행하는 한정 실험

보정된 기존 학습 풀을 클립·그룹과 이미지 중복 기준으로 train 33,228장, dev 4,636장으로 분리합니다. 부모 모델은 이 풀을 이미 학습했으므로 dev를 독립 시험셋이라고 부르지 않습니다. 공식 검증과 공개 장애물 회귀 자료는 이 후보의 best 선택·임계값 조정·학습 사례 선택에 사용하지 않습니다.

가설과 고정 설정을 먼저 기록하고, 기존 AI Hub best에서 최대 한 후보·3epoch만 추가 최적화합니다. 입력·학습률·손실 가중치·증강은 유지하며 확인된 원본 라벨만 수정합니다. 학습 구성의 재분할과 추가 최적화도 영향을 주므로, 결과를 라벨 수정 하나의 순수한 인과 효과라고 표현하지 않습니다.

후보 best는 dev에서 선택합니다. 출처별 비도로 오인율이 하나라도 늘거나 도로 IoU/재현율이 1퍼센트포인트를 초과해 떨어지면 채택 조건을 통과하지 못합니다. 적어도 한 출처의 오인율은 실제로 낮아져야 합니다. 이 기준은 개발 후보 선택용으로서 실제 차량 운용 승인 기준이 아닙니다. 후보 실패나 OOM은 보존하며 결과가 좋을 때까지 반복하지 않습니다.

3epoch 학습 후 개발 4,636장을 비교한 결과 사전 채택 조건을 통과하지 못했습니다. BDD에서는 오인율이 0.1849pp 낮아졌지만 IoU가 1.7539pp, 재현율이 2.5986pp 떨어졌습니다. AI Hub 주간 고속도로와 VKITTI에서는 오인율이 각각 0.1300pp, 0.1046pp 증가했습니다. 일부 오류 감소가 도로 누락 증가와 동반되고 출처별 변화 방향도 다르므로, 보정 라벨만으로 전체 회귀가 해결됐다고 볼 수 없습니다. 추가 후보를 반복하지 않고 고정 공식 보고셋 평가를 마친 뒤 이 실패도 보고합니다. [개발 비교 집계](../reports/corrected_development_comparison.json)

## 수정 영역 자체의 작은 표본 진단

개발셋에 실제 255→1 수정이 있는 3프레임을 예측 결과와 무관하게 전부 선택했습니다. 모두 주간 도심의 trafficDrum이며 warningTriangle과 야간은 없습니다. 기존 192×320 GT로 nearest 축소하면 수정 픽셀이 42개로 줄어들기 때문에, 원본 좌표의 1,482픽셀 ROI를 별도 CPU FP32·입력384×640·임계값0.65 조건으로 확인했습니다. 모델마다 프레임당 한 번씩 총 6회 추론했고 속도는 측정하지 않았습니다.

부모→후보의 ROI 도로 오인은 **96/1,482=6.4777% → 199/1,482=13.4278%**, +6.9501pp였습니다. 동일 3프레임의 주석 도로 재현율도 94.3652→93.6719%로 0.6934pp 낮아졌습니다. 이 작은 진단은 보정 대상에서 개선됐다는 근거도 제공하지 못합니다. 3프레임은 부모에게 노출된 개발 자료이며, 학습 분할과 추가 최적화도 바뀌었으므로 라벨 수정이 악화를 일으켰다고 단정할 수 없습니다. 원본 ROI 결과는 공식 CUDA/192×320 GT 지표와 합산하지 않습니다. [진단 집계·조건·한계](../reports/corrected_roi_diagnostic.json)

## 추가 데이터의 선택

ACDC는 야간·안개·비·눈의 픽셀 라벨과 대응 정상 조건 영상, 불확실 영역 정보를 제공하는 데이터입니다. 악조건의 의미 분할이 쉬운 문제가 아니라는 점도 원 논문에서 확인할 수 있습니다. [ACDC 원 논문](https://openaccess.thecvf.com/content/ICCV2021/html/Sakaridis_ACDC_The_Adverse_Conditions_Dataset_With_Correspondences_for_Semantic_Driving_ICCV_2021_paper.html)

실제로 확보한 ACDC 야간 학습 라벨 400장을 검사하면 person이 있는 프레임은 190장, rider 121장, motorcycle 90장, bicycle 96장입니다. 이는 객체 개수가 아니라 해당 라벨이 하나 이상 있는 프레임 수입니다. 현재 AI Hub의 빈틈을 보완할 가능성이 있어 RGB와 정답의 짝·전체 해독·내부 중복·공식 분할을 검증했습니다. train 1,600/val 406쌍의 준비와 독립 재검증이 완료됐습니다. 후속 감사에서 기존 train/dev 37,864장·공식 21,489장·public 40장 고정 기록과 정확한 바이트/RGB 중복 0건을 확인했습니다. 유사 장면과 모든 조상 사전학습의 중복을 배제한 것은 아닙니다. [교차 감사](../reports/acdc_cross_source_audit.json) 다운로드나 전처리 완료를 새 모델의 성능 개선으로 표현하지 않습니다. 이번 보정 후보에는 ACDC를 섞지 않아 비교 대상을 바꾸지 않습니다.

이미 보유한 A2D2는 별도 센서·카메라 자료를 검토할 수 있지만, 동기화·보정·태스크 적합성과 이용 조건을 먼저 확인해야 합니다. NightOwls의 검출 상자는 픽셀 단위 도로 정답을 대신하지 못합니다. 데이터 규모를 늘리는 것보다 빠진 조건과 필요한 종류의 정답을 맞추는 것이 우선입니다. [데이터와 이용 조건](DATASETS.md)

| 대안 | 해결하려는 문제 | 현재 선택과 검증 필요성 |
|---|---|---|
| 공통 모델에 실제 야간 라벨 보강 | 야간 장애물 감독 신호 부족 | 가장 직접적인 다음 데이터 실험 후보. 낮·밤·출처별 회귀를 함께 검사해야 함 |
| 주야간 별도 모델 또는 공유 백본+조건별 모듈 | 조명별 표현 차이 | 분리 모델의 우위가 아직 측정되지 않음. 황혼·터널·카메라별 혼합 조명의 조건 선택 오류까지 비교해야 함 |

| 알려지지 않은 장애물 검출 | 도로/비도로 두 클래스가 낯선 물체를 놓치는 문제 | Mask2Anomaly 같은 별도 이상 탐지 계열을 조사. 해당 논문의 점수를 우리 모델의 개선량으로 사용하지 않음 |
| 밝기 복원 전처리 | 저조도 노이즈·명암 손실 | 보기 좋은 영상이 정확한 인식이라는 보장이 없음. 원본과 변환 입력의 오인율·도로 재현율을 같은 정답으로 비교해야 함 |
| 온라인 시험 시 적응 | 운용 중 조건 변화 | 모델이 운용 중 바뀌면 출처·회귀·복구 조건도 바뀜. 이번 고정 체크포인트 연구에서는 적용하지 않음 |
| 작은 모델로 증류·양자화 | 탑재 메모리와 지연 | 정확도 검증 뒤 고려. 사용자가 취소한 이번 속도 측정은 재개하지 않음 |

위 연구 방향의 원문: [GCMA](https://openaccess.thecvf.com/content_ICCV_2019/html/Sakaridis_Guided_Curriculum_Model_Adaptation_and_Uncertainty-Aware_Evaluation_for_Semantic_Nighttime_ICCV_2019_paper.html), [Mask2Anomaly](https://openaccess.thecvf.com/content/ICCV2023/html/Nandan_Unmasking_Anomalies_in_Road-Scene_Segmentation_ICCV_2023_paper.html), [Master of All](https://www.ecva.net/papers/eccv_2022/papers_ECCV/html/4043_ECCV_2022_paper.php). 주야간 모델과 경량화 문헌의 상세 비교는 [주야간 연구 메모](DAY_NIGHT_PERCEPTION_RESEARCH.ko.md)를 참조합니다.

## 다음 개선의 우선순위와 채택 조건

이번 제한 실험의 결과를 보고 공식 검증셋에 맞춰 임계값을 조절하지 않습니다. 후속 실험이 별도로 승인되면 다음 순서를 우선 검토합니다. 아래는 실행 결과가 아닌 비교 설계입니다.

1. **정답 의미와 감독 분포 정리:** drivable area/road surface/freespace의 차이를 표로 명시하고 출처별 유효 road/nonroad 픽셀 및 그룹 수를 맞춥니다. 희소한 83프레임 보정과 별개로, 학습 배치의 출처 균형이나 기존 비도로 표본 유지율 하나만 바꾸는 대조 실험이 필요합니다. 데이터 수 증가만으로 동일한 감독 효과를 기대하지 않습니다.
2. **실제 야간·악조건 자료 보완:** 준비한 ACDC에서 보행자·이륜차·어두운 정지물체의 주석을 활용하되 기존 보호 집합과의 중복, 조건별 분할, 원래 Cityscapes 라벨의 의미를 먼저 확인합니다. 개발·최종 보고 집합은 후보 비교 전에 고정하며 현재 공식/public 표본을 새 학습 사례로 재사용하지 않습니다.
3. **도로와 장애물 판단 분리:** 도로 표면의 외형만 맞히는 이진 분할에 모든 장애물 판단을 맡기지 않는 구조를 검토합니다. 별도 검출/이상 탐지/점유 추정과 결합하더라도 낯선 물체·가림·거리별 놓침·오검출을 함께 측정해야 합니다. 낯선 객체를 무조건 도로가 아니라고 예측하게 해 recall을 떨어뜨리는 방식은 개선으로 채택하지 않습니다.
4. **도메인 보존과 효율 비교:** 학습/개발 데이터만 이용해 출처별 replay나 부모 예측 보존 항을 한 요소씩 비교할 수 있습니다. 부모 오류까지 그대로 유지할 수 있는 증류의 한계를 함께 확인합니다. 구조 경량화·양자화·조건별 모듈은 정확도 회귀를 확인한 다음 별도 하드웨어 평가가 필요하며 이번 취소한 속도 측정을 자동 재개하지 않습니다.

개선 판정에는 평균 IoU뿐 아니라 각 출처·주야간의 road recall, 일반 및 장애물 오인, 작은 물체의 크기·거리별 누락, 시간축 오류 지속을 함께 사용해야 합니다. 현재 자료에는 일부 항목의 정답이 없어 점수를 산출하지 못합니다. 소프트웨어 변경이 새 센서 정답이나 독립 시험을 대신하지 않습니다.

## 실제 주행 전에 남는 기능

분할 모델은 물체까지의 거리·상대 속도·예측 이동·점유 공간·통행 규칙의 정답을 제공하지 않습니다. 다중 카메라 시간 동기화, 노출 시각, 보정 오차, 작은 장애물의 거리별 누락, 가려진 객체, 실제 제동과 조향 응답도 별도로 검증해야 합니다. 현재 RC 계획·제어와 센서 실패 검사는 소프트웨어 회귀 자료입니다.

새 YOLO 의미 분할 어댑터는 검증된 보고서와 가중치를 오프라인 인식 코드로 연결합니다. 이 백엔드의 실제 차량 제어는 명시적으로 차단합니다. 인식 어댑터 추가를 완성된 자율주행 기능으로 표현하지 않습니다. 자세한 미검증 범위는 [LIMITATIONS](LIMITATIONS.md)에 기록합니다.
