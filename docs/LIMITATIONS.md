# 범위와 검증 한계

이 저장소는 카메라 기반 도로 영역 분할, 데이터 품질 검사, 오프라인 평가와 RC 제어 소프트웨어 연구를 위한 코드입니다. 도로 마스크 출력만으로 실제 차량을 운용할 수 있는 완성된 자율주행 시스템은 아닙니다.

## 측정한 것과 측정하지 않은 것

| 항목 | 현재 근거 | 해석 범위 |
|---|---|---|
| 도로 분할 | 고정 검증 21,489장, 7개 출처; 기존 3모델은 두 입력 크기, 보정 후보는 384×640만 | 해당 자료의 주석된 픽셀에 대한 오프라인 성능 |
| 장애물→도로 오인 | RoadObstacle21 30장, RoadAnomaly21 10장 | 표시된 장애물 픽셀의 오류율; 전체 숨김 시험셋 점수가 아님 |
| 작은 장애물 | 원본 public GT 픽셀을 분모에 유지 | 객체별 누락률·물체 크기·거리별 감지율은 미측정 |
| 처리 속도 | 요청에 따라 이번 비교 측정 취소 | 새 모델의 속도 개선률을 주장하지 않음 |
| 보정 라벨 | 84프레임 재처리 중 83프레임의 137,436픽셀 수정 | 전처리 정확성 검사이며 학습 성능 향상의 증거가 아님 |
| 오프라인 제어·센서 실패 | 합성 fixture 기반 소프트웨어 회귀 | 실제 센서·차체·브레이크 검증을 대체하지 않음 |
| 80km/h 운용 | 속도·시간 동기화·보정·제동 자료 부족 | 미검증 |

## 라벨의 의미

`road_surface_v1`은 `0=road`, `1=nonroad`, `255=ignore`인 연구용 이진 공간입니다. BDD의 drivable area, Virtual KITTI의 Road 표면, AI Hub의 freespace는 서로 다른 원래 작업입니다. 이를 하나의 숫자 공간에 매핑해도 통행 가능성·차량 폭·경사·노면 상태·정지 가능 거리까지 같은 정답이 되는 것은 아닙니다.

일반 비도로 픽셀에는 차량뿐 아니라 보도·울타리 등도 포함됩니다. 일반 `false_road_rate`를 장애물 객체 누락률이나 충돌 확률로 읽으면 안 됩니다. 반대로 주석이 없는 영역을 nonroad로 단정하면 거짓 정답을 만들 수 있으므로 무시 픽셀을 유지합니다.

AI Hub는 출처/분할에 따라 약 72–80%가 무시 픽셀이었습니다. 새 개발 분할의 출처별 비율은 달라질 수 있습니다. 이 범위는 모든 프레임이 동일하다는 뜻이 아닙니다. 공식 평가도 유효 주석 영역만 평가합니다.

## 야간 성능과 모델 분리

기존 야간 고속도로 검증 785장에는 pedestrian, bicycle, motorcycle, rider, rubberCone 주석이 없습니다. 기존 야간 학습에서 해당 클래스가 있는 프레임은 각각 2·2·3·2·8장뿐입니다. 야간 도로 IoU가 높아져도 이 물체들의 야간 인식이 검증된 것은 아닙니다.

따라서 현재 근거로 주간 모델과 야간 모델의 분리가 더 좋다고 결론 내리지 않습니다. 분리 모델은 전환 경계·황혼·터널·역광에서 선택 오류를 추가하고 유지할 모델 수도 늘립니다. 우선 공통 모델의 출처/조건별 성능을 확인하고, 균형 있는 별도 개발 자료를 확보한 뒤 단일 모델과 조건부/분리 모델을 같은 조건에서 비교해야 합니다. 관련 문헌 검토는 [연구 메모](DAY_NIGHT_PERCEPTION_RESEARCH.ko.md)에 있으며 구현·효과 검증 결과와 구분합니다.

## 데이터 분리와 노출 이력

- 공식 검증셋은 이전 학습에서 best checkpoint 선택에 쓰였습니다. 블라인드 시험셋이라고 부르지 않습니다.
- public 40장은 반복 사용한 개발 회귀 자료입니다. 이번 학습·임계값 튜닝·사례 선택에는 쓰지 않았지만 독립적인 숨김 최종 시험은 아닙니다.
- 새 train/dev는 기존 학습 풀을 그룹으로 나눴습니다. 초기화에 사용되는 부모 모델은 그 풀을 이미 보았으므로 개발셋 역시 부모 모델에 독립적이지 않습니다.
- AI Hub의 장치/날짜 파일명 그룹은 보수적인 대리 그룹입니다. 물리적으로 독립된 모든 주행을 증명하는 메타데이터는 아닙니다.
- 알려진 로컬 경로·origin/clip·바이트·RGB 중복은 검사합니다. 외부 사전학습 전체의 내용 중복은 확인할 수 없습니다.
- 기존 BDD 검증의 두 중복쌍은 계약에서 반복 가중을 명시해 원래 분모를 보존했습니다. 출처 간 중복은 허용하지 않습니다.

## 전처리 검증의 경계

다각형 검사는 크기, 유한 좌표, 경계, 고유점, 0이 아닌 면적을 확인합니다. 모든 자기교차나 의미상 라벨 오류가 없다는 보장은 아닙니다. 원본 표본을 육안 검토했으나 전 프레임 의미 검수를 완료한 것은 아닙니다.

전처리에서는 기존 학습 이미지의 바이트 해시와 마스크 해독, 원본 annotation 해시를 확인했습니다. RGB 해시는 바이트가 같은 이전 전체 해독 결과에서 계승했습니다. 공식/public 데이터의 현재 이미지와 마스크를 다시 해독한 검사가 아니라, 고정 계약의 해시 기록과의 교차 검사입니다. 현재 디스크의 모든 공식 데이터가 당시와 같다는 새 증명으로 확대하지 않습니다.

`trafficDrum`과 `warningTriangle` 보정은 확인된 감독 신호 누락을 수정했습니다. 그 수정만으로 모든 회귀 원인이 해결되었다고 주장하지 않습니다. 예측을 정답으로 변환하지 않으며, 원본 이미지·기존 마스크·공식 평가 정답을 덮어쓰지 않습니다.

## 하드웨어와 운용

RTX 3080 Laptop의 PyTorch 할당기 상한 3/5/7GiB는 실제 4GB 또는 8GB GPU의 실행 측정이 아닙니다. CUDA context·다른 프로세스 메모리는 그 상한 밖에 있습니다. 하나의 녹화 영상을 복제한 다중 입력은 동기화된 독립 8카메라 차량 실험이 아닙니다.

공개 기본 설정은 dry-run이며 실제 제어 승인 상태가 false입니다. 테스트 통과, 학습 완료, 높은 IoU 어느 것도 실제 차량 운용 승인·무사고·고속 충돌 방지를 뜻하지 않습니다. 센서 보정, 시간 동기화, 지연, 제동, 비상 정지와 운용 환경별 검증이 별도로 필요합니다. 설치·테스트·문서 열람은 학습, 모델 자동 교체, 자동화, systemd 서비스 또는 실제 제어를 시작하지 않습니다.
